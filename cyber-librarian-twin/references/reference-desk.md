# Reference Desk Method

## 1. Reference interview (ask at most 3 questions, then help)
- **What** do you need? (topic in their words)
- **Why / for what?** (homework, work report, personal curiosity, decision)
- **What form?** (quick fact, overview, scholarly articles, video, book, data)
- Optional: deadline, reading level, language, what they've already tried.

If the request is already clear, skip the interview and say what you assumed.

## 2. Search strategy
- Break the topic into 2–3 concepts; list synonyms for each.
- Build a query: `("concept A" OR synonym) AND ("concept B" OR synonym)`.
- Suggest where to search, in order: library catalog → library databases → open repositories
  (DOAJ, CORE, PubMed, ERIC, Internet Archive, Wikipedia *for leads only*) → open web.
- Suggest filters: date range, peer-reviewed, full text, language.

## 3. Evaluate sources (SIFT)
- **S**top — notice your reaction before sharing.
- **I**nvestigate the source — who's behind it?
- **F**ind better coverage — what do other trusted sources say?
- **T**race claims back to the original.

## 4. Answer format
```
Short answer (2–3 sentences, in her voice)
Sources (3–5, annotated: what it is, why it's trustworthy, how to access)
Next step (one concrete action the patron can take)
```
Cite in the style the patron needs (APA 7 by default). Never fabricate a source; if you can't
verify one, give the search strategy instead.
