# Video Production

## Formats
| Format | Length | Aspect | Notes |
|--------|--------|--------|-------|
| Reel / Short / TikTok booktalk | 30–60 s | 9:16 | Hook in first 2 s, one book or one tip |
| Digital-literacy tip | 60–90 s | 9:16 or 1:1 | One skill, one demo, one takeaway |
| Database / e-book tutorial | 2–4 min | 16:9 | Screen recording + avatar picture-in-picture |
| Virtual library tour | 3–6 min | 16:9 | Photo/video B-roll of spaces + narration |
| Workshop recording | 10–30 min | 16:9 | Chapters every 3–5 min |
| Welcome / announcement | 20–45 s | 16:9 + 9:16 | Avatar talking head |

Speaking rate: ~150 words/min (≈ 2.5 words/s). A 60 s video ≈ 140–150 words.

## Script template
```
TITLE:
PLATFORM / ASPECT / LENGTH:
AUDIENCE:
GOAL (one sentence):

[HOOK 0:00–0:03]  (question, surprising fact, or "Did you know…")
[INTRO]           Signature greeting + who she is (1 line)
[BODY]            3 beats max; each beat = 1 idea + 1 visual
[CALL TO ACTION]  borrow / visit / try / share
[SIGN-OFF]        Signature sign-off
[DISCLOSURE]      "AI-generated with <name>'s permission." (if avatar/clone voice used)
```

## Storyboard / shot list (table)
| # | Time | Visual (what's on screen) | Narration | On-screen text | Audio/SFX |
|---|------|---------------------------|-----------|----------------|-----------|

Visual types: `AVATAR` (talking head), `SCREEN` (screen capture), `PHOTO` (still with slow
zoom), `BROLL` (stock or own footage), `TITLE` (text card in brand colors).

## Production paths
1. **Avatar video** — send narration to the avatar tool with her `avatar_id`; add captions.
2. **Voice + visuals** — generate voice-over (see `voice.md`), then assemble photos/screen
   captures in an editor (CapCut, Canva, DaVinci Resolve) or an HTML video composition.
3. **Real recording** — give her the script as a teleprompter version (short lines, one
   sentence per line, bold the stressed words).

## Accessibility checklist
- Burned-in or sidecar captions (`scripts/make_srt.py`)
- On-screen text ≥ 4.5:1 contrast, stays ≥ 2 s
- Describe important visuals in narration (audio description lite)
- Transcript in the post description or linked
